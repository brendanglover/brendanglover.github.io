# Personal Portfolio Conventions

## Project Overview
Personal portfolio site at brendanglover.github.io via GitHub Pages. Cyberpunk aesthetic. Single page, zero dependencies, vanilla HTML/CSS/JS only.

## Identity
- Name: Brendan Glover
- Role: Data Automation Specialist at Incubeta, Cape Town
- Also: Hobbyist welder, maker, YouTube creator (@heavymetalbren)
- Tone: Professional but personal — reflects both the tech side and the maker side. Never generic or corporate.

## Design
- Aesthetic: Cyberpunk — dark backgrounds, neon accents, high contrast
- Never water down the personality or make it look like a template

## Projects to Feature
- GapCalc (gapcalc.com) — free workshop calculator for welders and makers
- Zink. (gotzink.com) — free productivity tools for writers and sellers
- HMB YouTube Channel (@heavymetalbren) — welding and DIY content

## Rules
- Always explain a change before making it
- Maintain the cyberpunk aesthetic on all changes
- Never add dependencies or npm packages
- Three separate Git commands always: git add . then git commit then git push
- Commit messages: lowercase, descriptive, no emoji
- GitHub Pages deploys on push to main
