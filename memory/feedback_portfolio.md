---
name: Portfolio Conventions
description: Rules for working on the brendanglover.github.io portfolio — git workflow, dependencies, aesthetics
type: feedback
---

Always explain a change before making it.

Never add npm packages or any external dependencies — the site is intentionally zero-dependency vanilla HTML/CSS/JS.

Maintain the cyberpunk aesthetic (dark backgrounds, neon accents, high contrast) on all changes. Never water it down to look like a template.

Git workflow is always three separate commands: `git add .` → `git commit` → `git push`. Commit messages: lowercase, descriptive, no emoji.

**Why:** These are explicit user-defined conventions for the portfolio project.

**How to apply:** Every time code is changed or committed in this repo.
